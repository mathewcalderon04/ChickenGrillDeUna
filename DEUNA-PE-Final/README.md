# DEUNA.PE — Chicken & Grill

Sitio web adaptable desarrollado para la **Evaluación Final** del curso de Desarrollo Web.

## Tecnologías

- HTML5 semántico
- CSS3 personalizado (animaciones)
- Bootstrap 5.3 (diseño responsive)

## Estructura

```
DEUNA-PE-Final/
├── index.html          → Inicio
├── nosotros.html       → Sobre nosotros
├── carta.html          → Menú / Carta
├── promos.html         → Promociones
├── resenas.html        → Reseñas de clientes
├── contacto.html       → Pedidos y ubicación
├── css/
│   └── estilos.css     → Estilos + 5 animaciones CSS
├── img/                → Imágenes (fondo, mapa, etc.)
└── README.md
```

## Animaciones CSS incluidas (5+)

1. **Subrayado deslizante** en los enlaces del menú
2. **fadeInUp** — entrada suave del título y textos del hero
3. **Elevación de cards** al pasar el mouse (translateY + sombra)
4. **Escala / pulso** en botones (hover scale + glow)
5. **Desplazamiento** de ítems de lista al hover
6. **Bonus:** brillo suave (text-shadow) en el título principal

## Cómo publicar en GitHub Pages (cuenta nueva)

1. Crea una cuenta nueva en GitHub (o usa una existente distinta).
2. Crea un repositorio nuevo (ej: `DEUNA-PE` o `chicken-grill`).
3. Sube **todos** los archivos de esta carpeta.
4. Ve a **Settings → Pages → Source: Deploy from a branch → main / root**.
5. En unos minutos estará en:  
   `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`

## Imágenes

Copia las imágenes de tu proyecto anterior a la carpeta `img/`:

- `fondo_deuna.png` (fondo)
- `maps.jpg` (mapa de ubicación)

Si no tienes el fondo, el sitio funciona igual con el color oscuro de respaldo.
